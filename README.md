# مجموعة ساجي

مجموعة أقسام لصفحات الهبوط في سلة. التاجر يختار قالباً من قنوات البيع ثم صفحات الهبوط، ويعدل النصوص والصور من لوحة التحكم.

المستودع: https://github.com/Ashaheen892/tw-saji-landing

## الصفحات

كل صفحة تبدأ برأس الصفحة، ثم ستة أقسام، وتنتهي بفوتر الصفحة. الرأس والفوتر يتكرران لأنهما إعداد مشترك، وبقية الأقسام لا تتكرر.

بيانات المعاينة تختلف مع القالب: وضوح يعرض سيروماً، وزخم حقيبة جلد، وساجي قهوة محمصة. الصور والفيديو من Pexels ويمكن استبدالها من إعدادات القسم.

رأس الصفحة يبدّل الفاتح والداكن بأيقونة قمر وشمس. الفوتر يعرض روابط المتجر، وشارات بصور وروابط مثل وثيقة العمل الحر ومنصة الأعمال.

### وضوح — `templates/wuduh.json`

الصفحة الافتراضية لأي متجر.

1. رأس الصفحة
2. سلايدر افتتاحي
3. هيرو المنتج
4. صف الوعود
5. فيديو افتتاحي
6. لقطتان
7. دعوة الختام
8. فوتر الصفحة

### زخم — `templates/zakham.json`

صفحة قرار الشراء: صورة، أرقام، أسباب، مقارنة، ومحتوى الصندوق.

1. رأس الصفحة
2. واجهة الرصيف
3. شريط الأرقام
4. سكة الأسباب
5. لوحة المقارنة
6. لوحة العرض
7. اختيار الموقف
8. فوتر الصفحة

### ساجي — `templates/saji.json`

صفحة التفاصيل: محتوى الطلب، أوقات الاستخدام، المنشأ، العناية، ورسالة المتجر.

1. رأس الصفحة
2. بطاقة المنشأ
3. إيصال المحتوى
4. أوقات اليوم
5. خيط العناية
6. رسالة الصانع
7. بطاقات الرف
8. فوتر الصفحة

في صفحة منتج، أزرار الشراء تفتح الشراء السريع الخاص بالصفحة. في صفحة العروض تتبع رابط الزر الرئيسي.

ريلز التجارب قسم إضافي يُضاف من قائمة الأقسام: فيديوهات عمودية قصيرة لتجارب العملاء وآرائهم، مع اسم العميل وزر شراء. عند الوصول للقسم تعمل الفيديوهات كلها بدون صوت، والصوت يُفتح من زر كل فيديو.

## التطوير

```bash
pnpm install
pnpm dev
pnpm build
pnpm audit:salla
```

المعاينة المحلية: `http://localhost:5173/node_modules/.salla-temp/index.html`

بعد الربط في لوحة شركاء سلة، فعّل ميزة قوالب صفحات الهبوط ثم انشر القالبين من المعاينة:

```bash
pnpm build && pnpm exec tw-preview
```
